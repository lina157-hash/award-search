# 國泰獎勵機位定時查詢腳本（cathay-runner）

這個小程式在**你自己的電腦**上執行：打開一個有記憶的 Chrome 視窗，用你已登入的國泰帳號，照「機票搜索雷達」網站上的
「國泰定時查詢」清單搜尋航線，沿著「選擇航班」頁的 7 天日期列往後翻，記下每天各艙等有沒有位、最低里數，然後上傳到網站。
之後任何人在網站查同一條航線，結果上方就會多一張「國泰官網實查」卡片和月曆。

- **不碰密碼**：第一次執行時，請你自己在打開的視窗登入國泰；之後 `profile/` 資料夾會記住登入狀態。腳本不會輸入、讀取或
  儲存任何密碼，也不會讀 cookie。設定檔裡的 `passcode` 是**網站的通關密碼**（上傳用），**不是國泰密碼**。
- **像真人一樣慢**：每個動作之間隨機停 3～7 秒，一次最多 3 條航線、60 天，預設一天一輪。遇到登入頁、驗證碼、「拒絕存取」或
  空白頁就停下來並寫進紀錄，不會一直重試。
- **風險**：國泰的使用條款禁止自動化工具。這個腳本雖然慢、量少，仍可能被國泰偵測到，最壞的情況是帳號被限制。請自己評估，
  不要把速度調快、不要同時跑好幾份。

## 安裝（一次就好）

1. 安裝 Node.js：到 <https://nodejs.org> 下載 LTS 版，一路下一步。
2. 把 `tools/cathay-runner` 這個資料夾整個複製到你電腦上好找的地方（例如 `文件\cathay-runner`）。
3. 在資料夾裡開終端機（Windows：資料夾空白處按右鍵 →「在終端機開啟」；Mac：終端機 `cd` 進去），執行：
   ```
   npm install
   npx playwright install chromium
   ```
4. 把 `config.example.json` 複製一份改名成 `config.json`，用記事本打開，把 `passcode` 改成網站的通關密碼。其他先不用改。
5. 第一次執行（會開視窗，請在視窗裡登入國泰，登入好回到終端機按 Enter）：
   ```
   node run.js --route TPE-NRT
   ```
   看到 `TPE→NRT 經濟 42/60 天有位，最低 13,000；商務 …` 和 `已上傳到 …` 就成功了。

## 要查哪些航線

清單在網站上管理：在「航線查詢」查一條航線，結果上方按 **「加入國泰定時查詢」**（需要通關密碼）。首頁的
**「🛫 國泰定時查詢」** 面板可以看清單、移除航線、看腳本是不是在線上。腳本每次執行都會先去網站拿清單；網站拿不到時才用
`config.json` 裡的 `routes`。

## 兩種執行方式

### A. 監看模式（建議）：`node run.js --watch`

開著一個終端機讓它一直跑：每 60 秒問一次網站有沒有人按了 **「請腳本現在查這條」**（有就馬上查，一樣是真人速度），
每天 `dailyAt`（預設 07:30）把清單查一輪。網站上看得到「腳本：線上」。需要登入時終端機會提示你。

- Windows 開機自動啟動：在資料夾的終端機執行 `.\schedule-windows.ps1 -Watch`（會登記成「登入 Windows 時執行」，
  開一個終端機視窗）。取消：`.\schedule-windows.ps1 -Remove`。
- Mac：照 `com.award-search.cathay-runner.plist` 檔案開頭的說明改路徑、放到 `~/Library/LaunchAgents/` 再 `launchctl load`。
  背景執行時沒有終端機可以按 Enter，所以要先手動跑一次 `node run.js --route TPE-NRT` 把登入記住。

### B. 每天一次：`node run.js`

查一輪就結束，給工作排程器用。Windows：`.\schedule-windows.ps1`（預設每天 07:30，`-At 21:00` 改時間）。
Mac：plist 改成 `StartCalendarInterval`（檔案裡有說明）。這個模式沒有「現在就查」。

## config.json 的欄位

| 欄位 | 說明 |
| --- | --- |
| `site` | 網站網址，預設 `https://award-search-zeta.vercel.app` |
| `passcode` | 網站的通關密碼（上傳用）。**不是國泰密碼。** 也可以改用環境變數 `CXRUNNER_PASSCODE` |
| `cabins` | 要查的艙等，`Y` 經濟、`W` 豪華經濟、`J` 商務、`F` 頭等；清單上的航線各自可以設 |
| `pax` | 人數（目前只在首頁小工具預設 1 位；清單上的設定會寫進結果） |
| `daysAhead` | 從明天起查幾天，預設 60 |
| `maxRoutes` | 一輪最多幾條航線，預設 3 |
| `startDate` | 固定從哪天開始查（`2026-11-01`），空白就是明天 |
| `detailDays` | `true` 會逐天點進去記航班與里數（慢很多，約每天 1 次點擊）；`false` 只讀日期列的有位／不適用 |
| `dailyAt` | 監看模式每天查一輪的時間 |
| `pollSeconds` | 監看模式幾秒問一次網站，預設 60 |
| `pace` | 動作之間的隨機停頓秒數 `[最少, 最多]`，預設 `[3, 7]`，**請不要調低** |
| `headless` | `false`（預設）看得到視窗；`true` 看不到，但需要登入時就沒辦法處理 |
| `searchUrl` | 國泰如果以後有帶參數的結果網址才用：`{from} {to} {date} {pax} {cabin}` 會被代換；空白就用首頁小工具 |
| `browserChannel` | 填 `chrome` 會用你電腦上裝的 Google Chrome 而不是 Playwright 的 Chromium |
| `routes` | 網站清單拿不到時的備用清單：`[{ "fc": "TPE", "tc": "NRT", "fromName": "台北", "toName": "東京" }]` |

## 腳本怎麼找到結果頁

1. 開國泰首頁（zh_TW）的「預訂行程」小工具：開「使用里數兌換」、填出發地點、目的地、旅程類別「單程」、出發日期，按「兌換機票」。
   它只靠畫面上的文字（出發地點、目的地…）找欄位，不用國泰的程式碼名稱。
2. 任何一步找不到，就改成**半自動**：終端機印出「請在瀏覽器裡搜尋 台北 → 東京（1 位）…按 Enter」，你在視窗裡自己搜尋，停在
   「選擇航班」頁按 Enter，之後翻日期列的部分還是自動的。網站上會顯示「腳本在等你在電腦上手動搜尋這條」。
3. 在結果頁切換艙等用畫面上的「經濟客艙」「商務客艙」方塊；第二個艙等會倒著翻回來，少按一半。

## 紀錄檔（runner.log）會寫什麼

- `開始查 TPE→NRT（台北 → 東京）2026-10-16 ～ 2026-12-14…`：這條航線開始。
- `✓ 出發地點 台北（TPE）` / `✗ 出發日期`：首頁表單每一步有沒有成功；有 ✗ 就會改請你手動搜尋。
- `經濟艙：讀到 60 天，42 天有位`、`TPE→NRT 經濟 42/60 天有位，最低 13,000；商務 …`：結果摘要（`最低` 只有在 `detailDays`
  或日期列本身有印里數時才有）。
- `已上傳到 https://…（60 天）`：成功；`上傳失敗：…`：資料留在 `data/TPE-NRT.json`，下次一起上傳。
- `國泰要求登入。` → 到視窗登入後按 Enter。`國泰拒絕存取…這次先停下來`：被擋了，等幾個小時再試，不要一直重跑。
- `已存診斷資料到 runner-debug/…txt`：頁面長得和預期不一樣時，腳本會把那一區的結構（已去掉姓名、會員號碼、e-mail、里數餘額）
  和一張截圖存在你電腦上，**不會上傳**。把 .txt 貼給我們，就能依真實頁面調整。

結束代碼：0 成功、1 有航線失敗、2 設定或清單問題、3 被擋／需要登入而沒完成。

## 更新腳本

`cxcal-page.js` 是從網站的 `public/cxcal.js` 複製出來的讀頁程式（書籤小工具用同一套）。網站那邊改了之後，在這個資料夾執行
`node build.js` 就會更新；直接整個資料夾換成新版也可以（`profile/`、`data/`、`config.json` 留著）。
